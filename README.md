# Analizador Táctico Deportivo - La Voz de Manaure 92.3 FM

Herramienta web ligera para el análisis visual de jugadas de fútbol.

## Archivos del Proyecto
- `index.html`: Estructura HTML y cargador de archivos.
- `style.css`: Diseño oscuro y estilos de botones.
- `script.js`: Lógica de dibujo (Fabric.js) y exportación de imágenes.
- `README.md`: Descripción del proyecto.

## Cómo usar
1. Sube estos archivos a tu repositorio de GitHub.
2. Abre `index.html` en tu navegador.
3. Carga el video del partido.
4. Pausa en el momento clave, dibuja tus flechas y exporta la imagen para redes sociales.
